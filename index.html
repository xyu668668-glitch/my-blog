TOOL 01

趋势分析

arrow_outward

输入基金代码，查看趋势强弱、波段位置、回撤和白话建议。它不替代判断，而是把判断前的信息整理清楚。

类型基金投资 / 数据信号
方法趋势、回撤、波段、历史统计
状态线上可用，持续迭代
show_chart

TOOL 02

组合回撤

arrow_outward

输入基金或 ETF 代码和目标仓位，回测组合资金曲线、最大回撤、定投和再平衡效果，用来观察组合风险。

类型组合回测 / 回撤分析
方法累计净值、定投、再平衡、基准对比
状态线上可用
grid_on

TOOL 03

网格策略

arrow_outward

输入基金、ETF 或指数代码，自动测算 5 套价格触发规则和 5 套资金方案，比较收益、回撤、仓位和历史滚动胜率。

类型网格策略 / 资金方案回测
方法触发规则、资金计刚、滚动概率、满仓对比
状态线上可用
radar

TOOL 04

信号扫描

arrow_outward

批量扫描基金净值位置、趋势强弱、回撤修复和历史相似胜率，把今日基金板块、波段信号和风险名单整理成观察清单。

类型基金扫描 / 机会观察
方法低位高位、趋势强弱、回撤修复、历史胜率
状态线上可用
